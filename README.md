# CarLife AutoStarter (车机开机自启助手)

专门为 **Android 4.4（KitKat）车载车机系统** 打造的轻量级开机自启辅助工具。

## 🎯 功能特性

* **深度兼容 Android 4.4**：`minSdkVersion 19`、`targetSdkVersion 19`，纯原生 API 实现，体积极小（< 1MB），零三方依赖，秒级启动且无内存常驻占用。
* **车载快速开机适配**：除标准系统冷启动广播（`BOOT_COMPLETED`）外，同时监听车机/方案商常见的快速开机与微休眠广播（`QUICKBOOT_POWERON`）。
* **开机延时平稳拉起**：支持 0~30 秒延时启动调节（默认 8 秒），避开车机开机时桌面 Launcher、USB 通道和声卡驱动初始化的并发卡顿。
* **智能包名识别**：自动探测车机端已安装的 CarLife 客户端（优先匹配车载专用版 `com.baidu.carlifevehicle`，次选通用版 `com.baidu.carlife`），并支持在 UI 中自定义目标包名。
* **车载横屏交互**：高对比度暗黑界面设计，配备“立即测试启动”按钮，车机安装后可单点验证。

## 🚗 车机使用说明

1. **首次安装激活**：安装完成后，**必须在车机桌面上手动点击打开一次该应用**（解除 Android 系统的 `STOPPED` 广播拦截保护）。
2. **测试与配置**：进入应用后点击【立即测试启动】，确认能正常跳转进入 CarLife；根据车机开机速度调整延迟秒数（建议 6~10 秒），点击【保存配置】即可。
3. **白名单**：如果车机固件自带安全中心或车载卫士，请将本应用与 CarLife 设为允许自启和白名单保护。
