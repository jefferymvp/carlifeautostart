# CarLife AutoStarter (车机开机自启助手)

专门为 **车载车机系统** 打造的轻量级开机自启辅助工具。

## 🚀 兼容性实测结论（v1.0）

本项目已在以下硬件与环境完成真机端到端开机自启测试，均已**实测成功**：
* ✅ **Android 4.4（KitKat）真实车机系统**：通过测试，冷启动与断电重启均可稳定自动拉起 CarLife 车载端。
* ✅ **Android 9.0（Pie）雷电9模拟器**：通过测试，开机广播捕获与跨进程前台拉起焦点覆盖正常。

---

## 🎯 核心功能特性

* **深度向下兼容**：`minSdkVersion 19`、`targetSdkVersion 19`，纯 Android 原生 API 开发，包体积仅约 **68 KB**，零三方重型库，无需常驻后台，不消耗车机运存。
* **默认 30 秒安全延时**：系统默认采用 **30 秒** 开机延时拉起机制（支持在界面自由调节 0~60 秒），避开车机点火冷启动时系统桌面 Launcher、底层 USB Host 通道、声卡驱动初始化的并发卡顿高峰期。
* **全生命周期异步保活（`goAsync`）**：采用 Android 官方推荐的 `goAsync()` 机制，摆脱高版本 Android 后台启动 Service 限制，保障低版本与高版本系统广播生命周期完整执行。
* **车载快速开机与微休眠多重监听**：同时监听冷启动（`BOOT_COMPLETED`）、微休眠/快速开机（`QUICKBOOT_POWERON`）、加密就绪（`directBootAware`）以及亮屏解锁（`USER_PRESENT`）广播。
* **车载专用包名智能适配**：默认优先匹配车载专用定制版 `com.baidu.carlifevehicle`，次选通用版 `com.baidu.carlife`，并支持自定义包名输入与一键测试启动。
* **车载高对比度暗黑 UI**：横屏大按钮友好交互，方便车机屏幕触控调试。

## 🚗 车机安装与部署指南

1. **安装 APK**：
   * 将构建好的 `CarLifeAutoStarter.apk` 拷贝到 U 盘，在车机文件管理器中点击安装。
2. **【极其重要】首次手动点击“激活”**：
   * 安装完成后，**必须在车机桌面上手动点击打开一次该应用**（解除 Android 底层安全机制对新安装应用标记的 `STOPPED` 广播拦截保护）。
3. **参数配置与单点测试**：
   * 进入应用后，确认界面提示“已检测到车载版 CarLife”；
   * 点击 **【立即测试启动 CarLife】** 按钮，验证能否顺利跳转入 CarLife；
   * 默认开机延时已预设为 **30 秒**（可根据个人车机性能调整），确认无误后点击 **【保存当前配置】** 即可。
4. **车机系统白名单（如有）**：
   * 若车机 ROM 自带车载管家、省电优化或自启动管理，请将 **CarLife** 与 **CarLife自启动助手** 加入允许自启白名单。
